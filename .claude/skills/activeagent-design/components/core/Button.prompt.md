Action button; primary is solid red (#ef4444), use one primary per view.

\`\`\`jsx
<Button variant="primary" onClick={run}>New Agent</Button>
<Button variant="secondary" size="sm">Browse Templates</Button>
\`\`\`

Variants: primary (solid red), secondary (gray border), tertiary (gray fill), ghost, danger. Disabled = gray fill + muted text.

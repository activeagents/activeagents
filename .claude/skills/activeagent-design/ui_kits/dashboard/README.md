# Active Agent — Dashboard UI kit
Recreation of the product dashboard (the `actionagent` gem's `actionagent/frontend/components/dashboard/*`, in the github.com/activeagents/activeagent repo). Screens: Agents (fleet grid), Agent detail (tabs), Traces (waterfall), Metrics, Evaluations. Interactive: sidebar nav + dark/light toggle. Composes components/ primitives via the DS bundle.

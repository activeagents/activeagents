**Subheadline:**

```

### Feature Grid (3x3):

#### Agents are Controllers
```
Actions, callbacks, views. For agents.
Active Agent uses controllers.
```

#### Action::Prompt
```
Prompt templates. Like Action Mailer,
but for AI.
```

#### Any LLM
```
OpenAI, Anthropic, Ollama, and any with
OpenAI compatibility.
```

#### Resilient by Default
```
Queue, backoff, graceful failures, retries.
Active Agent makes agents resilient.
```

#### Streaming
```
Real-time responses. Pro: Agents ship
streaming by default.
```

#### Structured Output
```
JSON schemas, validated. Agent to API
interfaces.
```

#### Tool Calling
```
Actions use tools to get things done
directly. Web browsers.
```

#### MCP Support
```
Model Context Protocol. The new standard
for tool APIs.
```

#### Background Jobs
```
Solid Agent brings persistence for
background agent execution.

## Release steps (the 1.9.3–1.9.5 recipe)

1. Worktree from `origin/main`; bump `lib/active_agent/version.rb`,
   `actionagent/lib/action_agent/version.rb`, `browser-sidecar/package.json`
   and its lock; rename `## [Unreleased]` to `## [1.9.6] - <date>` with a
   short preamble.
2. Release PR against `main`; wait for the 12 checks; merge (no auto-merge
   on the repo).
3. `git tag -a v1.9.6 -m "activeagent and actionagent 1.9.6"` on the merge
   commit; push the tag. The Release workflow publishes RubyGems, npm and the
   ghcr sidecar image.
4. Host repin (below), staging smoke test, production dispatch.
